# 用户与需求讨论

更新：2026-10-01｜状态：简短讨论稿。

## 已确认

健身爱好者与篮球爱好者并列为首批目标用户。先做更容易分析的动作，不预先锁定篮球或健身其中一类。

## 用户需求假设

| 用户 | 想解决的问题，待后续验证 |
|---|---|
| 健身爱好者 | 看清训练动作，对照参考动作，观察动作幅度、节奏与重复一致性 |
| 篮球爱好者 | 看清投篮过程，对照参考模板，理解姿态与时序差异 |

教练可以作为参考素材或反馈来源；是否将教练作为直接使用者，以后再讨论。

## 以后逐步确定

- 第一批实际试用者是什么水平，在哪种场景使用？
- 首个动作选择哪一个？
- 用户第一次使用后，最希望看到什么结果？
- 哪些功能足以完成第一次试用？

现在不固定完整页面、用户系统、后台、社区或首版功能清单。下一次只讨论一个影响当前尝试的选择，再更新这里。
