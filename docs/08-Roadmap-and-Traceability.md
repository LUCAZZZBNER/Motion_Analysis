# 后续如何一起搭建

更新：2026-10-01｜状态：讨论顺序，不是固定开发计划。

## 当前已确定

健身爱好者与篮球爱好者并列优先。首个动作按实现难度与试验效果选择。

## 可以逐步讨论的顺序

1. 选择第一批用户的具体使用场景。
2. 选择首个动作，以及第一次最想看到的结果。
3. 确定在哪种设备或界面上尝试。
4. 做一次小试验，查看真实效果。
5. 根据反馈补功能，再考虑另一个动作。

这个顺序可以由用户调整，不绑定日期、版本号或里程碑。

## 协作约定

- 每次只询问当前需要决定的一个关键问题。
- 用户确认后再记为已确定；我的建议保持待确认。
- 暂时不必决定的内容留空，不替用户预设完整产品。
- 用户可以随时调整先后顺序和范围。
- 在功能逐步明确时修改现有笔记，避免不断新增文档。

技术栈、详细架构、数据契约、商业化与长期版本路线都等实际需要时再讨论。
