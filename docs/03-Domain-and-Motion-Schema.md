# 动作数据讨论

更新：2026-10-01｜状态：尚未制定正式数据规范。

## 保留的思路

视频是原始素材；提取出的动作数据用于展示与比较。一次动作与由多次动作形成的参考模板是不同概念。

## 首次试验可能需要的数据

- 视频时间与人体关键点。
- 一次动作的开始、结束位置。
- 实际需要展示的角度或节奏结果。
- 比较时使用的参考动作。

以上为候选内容，不要求第一次全部保存。选择首个动作与展示结果后，再确定最小数据结构。

## 到需要时再约定

时间、单位、关节名称和缺失值需要能被分析与展示程序一致理解。是否需要3D、身体档案、多样本统计或版本管理，随功能逐步决定。

当前不固定骨架点序、字段名、存储格式、数据库表或完整Motion Schema。
