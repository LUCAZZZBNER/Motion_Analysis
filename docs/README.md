# 产品讨论入口

更新：2026-10-01。文档随讨论逐步补充；未确认的内容不作为开发要求。

## 已确认

- 健身爱好者与篮球爱好者并列为首批目标用户。
- 从两类用户的动作中，优先实现更容易分析、能验证价值的动作。
- 产品帮助用户看清自己的动作，并与选定参考动作比较。
- 由用户逐步搭建产品；每次只讨论当前需要决定的问题。

优先尝试徒手深蹲，再比较篮球投篮的实现效果。首个动作、最小功能与实现方式仍需后续讨论和试验。
