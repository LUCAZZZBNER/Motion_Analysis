# MediaPipe Lite 本地小测试

已接入 **MediaPipe Pose Landmarker Lite**，模型在浏览器内识别。Python 只提供本地页面；没有完整前后端框架，也不调用云端。

## 怎么运行

1. 在本文件夹双击 **start.cmd**，保留弹出的启动窗口。
2. 用 **Chrome** 打开 **http://127.0.0.1:8000**。启动脚本会尝试打开默认浏览器；默认浏览器不是 Chrome 时，请自行在 Chrome 打开这个地址。
3. 选择自己的视频和参考视频，拖动视频下方进度条的绿色开始端点、橙色结束端点；视频会跳到对应时刻。也可输入秒数微调，两个端点同步更新，每段最多选 20 秒。
4. 点击 **先测试一帧**，确认识别出了本人骨架，再点 **分析两段视频**。
5. 在 3D 视图拖动鼠标旋转，滚轮缩放；Shift＋拖动或右键拖动平移，双击重置。支持正面、侧面、俯视，骨架重合或并排，以及所选关键点的三维轨迹。对比进度滑块可同时切换两段姿态。
6. 查看三维关节角度、XY 轨迹投影和 X/Y/Z 曲线；需要时下载 CSV、原始 XYZ 关键点 JSON、采样骨架标注片段。

两段视频应是同一种动作，单人全身入镜、镜头固定、拍摄方向相近。建议首次各选 5–10 秒，MP4/H.264、480p 或 720p。视频可以留在原目录，选择文件不会上传或复制到项目。

关闭启动窗口即可停止服务。浏览器里的 **清空结果与视频** 会释放本次视频引用和结果。导出文件由浏览器保存到你选择的下载目录，不会自动写入项目。

## 还需要下载什么

**本机现在无需再下载或安装。** 启动脚本优先使用已有 Codex Python，其次使用已安装 Python；无需 pip、Node.js、NPM、PyTorch、CUDA、账号或 API Key。

## 轻量限制与解释

- 用户要求：硬盘 ≤5 GB、运行内存 ≤1 GB。这里的 GB 按十亿字节计算。
- 每个输入文件 ≤100 MiB，分辨率 ≤720p 像素量、最长边 ≤1280；竖屏 720×1280 可以。
- 每段选取区间 ≤20 秒，每秒识别 2 / 4 / 8 帧，每段最多 160 帧。
- 推理画面最长边 480，两段依次识别；每段结束销毁模型线程，不保存整段解码帧。标注导出最多缓存 32 MiB 编码数据。
- 页面提供可获得的内存读数和接近上限时的停止处理；该读数不能替代浏览器完整进程占用。真实视频仍需在任务管理器核对 1 GB 上限，浏览器自身无法保证跨设备的绝对内存封顶。

默认显示全部 33 个关键点：身体 12 点、脸部 11 点、粗略手部 6 点、脚部额外 4 点。可以切换简洁模式、显示点号；轨迹可选择全部 33 点。低置信度或缺失点不显示。3D 数据使用 Lite 模型已有的 worldLandmarks 输出，没有新增模型、渲染依赖或增加推理分辨率。

手部点只表示拇指、食指、小指的粗略位置，不包含完整指节；如需手指弯曲，后续可评估额外的 [Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker)，需要先确认下载目录和内存预算。

3D 视图和角度计算直接使用 XYZ；不是把二维点放在一个平面上旋转。姿态以每帧髋中心对齐，按各段固定中位躯干长度缩放，显示 Y 向上、Z 朝向默认正面视点。模型世界坐标本身以髋为原点，不提供场地内的真实位移。

这是从单目视频估计出的 3D 骨架，不是人体表面网格或精确扫描；遮挡、深度和拍摄方向会影响结果。两段按采样时间进度对齐，没有自动切分重复动作或自动匹配阶段，也不自动校正两段的拍摄方向。角度差异不是动作质量分数；人体模型不识别篮球或球轨迹。

CSV 包含三维角度与所选关键点的归一化 X/Y/Z 曲线。JSON 格式版本 2：worldPoints 保存原始模型估计坐标 `[x_m,y_m,z_m,confidence]`，points 保留用于原片标注的 `[x_px,y_px,confidence]`；缺失值为 null，并包含点号名称和坐标说明。

标注导出是选取区间的**采样无声片段**，按采样帧率生成，优先 MP4，浏览器不支持时用 WebM；不会保留原片帧率或声音。

## 已验证与下一步

已验证真实模型加载、CPU 调用和 160 帧无人画面返回缺失的 2D / XYZ 关键点；拖动选段、时间预览同步、3D 旋转缩放及视角切换、图表与导出另用固定 XYZ 测试。10 项几何及选段测试通过，包含三维角度的旋转不变性、深度保留、镜像和缺失点处理。没有把测试关键点加入正常识别流程。

本机最新自动测试中，Chrome 相关进程工作集采样最大约 779 MB，Python 服务约 24 MB（峰值约 26 MB），合计观测约 806 MB；这是测试场景的观测值，不是所有视频的保证。测试记录在本地 .test/verification.json，测试图片不代表真人识别结果。

**真人动作识别效果、两段真人视频的内存峰值尚待实际素材验证。** 下一步只需准备两段短视频试用，再根据效果决定是否继续，不预设完整产品方案。

端口占用时，在本目录运行 `./start.ps1 -Port 8001`，然后打开对应地址。`setup.ps1` 现在只检查资源，不下载或安装；不要沿用旧版本的 pip 安装步骤。
